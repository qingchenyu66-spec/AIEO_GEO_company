# GEO 系统操作说明（销售 / 运营 / 交付）

登录：`https://www.aieokj.com`

- **平台运营端**：管客户、配监测、审批、出报告、售前诊断。
- **客户企业端**：看自家数据、报告、知识库。登录后身份不对就右上角切身份。

左侧菜单因权限不同会少项；没有某个按钮 = 没开权限，找管理员。

每改完配置，点对应的 **保存**。需要审批的账号，保存后要等 **操作审批** 通过才真正生效。

| 企业管理 | 建企业、配词、配平台、配计划（核心） |
| 售前诊断 | 潜客未签约前的诊断任务 |
| 快照补录 | 抓取失败时人工贴答案重算 |
| 报告中心 | 看 / 导出报告 |
| 用户管理 | 账号、职位、权限 |
| 品牌洞察 | 选企业后看提及率 / 排名 / 情绪（有权限才有） |
| 信源分析 | 选企业后看引用信源（有权限才有） |
| 模型平台 | 平台目录、上下架、探活 |
| 预警阈值 | 队列积压、业务指标阈值 |

## 1. 运营总览

打开看 KPI、趋势，基本是只读。

没有数据：先确认下面企业管理里企业已配词、已配计划，且服务状态是「服务中」。

---

## 2. 操作审批

销售改企业 / 用户 / 部分操作会进这里，**不点通过就不生效**。

1. 进 **操作审批**。
2. 筛：待审批 / 已通过 / 已驳回 / 全部。
3. 展开看变更前后。
4. 对：点 **通过**（确认框再确认一次）。
5. 不对：点 **驳回**，可写原因。

通过后界面说「已执行」= 改动已经写进库。  
点完通过却报错：先刷新看状态是否已变成已通过；已通过就别反复点，把报错截图给技术。

---

## 3. 企业管理（核心，必会）

### 3.1 新建企业

1. **企业管理** → **新增企业**。
2. 填：企业名称、服务开始日期、服务结束日期。
3. **确认新增**。

列表没有「新增企业」= 没权限。

### 3.2 列表操作

- 筛：企业名称 / 服务状态 / 归属销售 → 刷新企业。
- **详情**：只看概况。
- **编辑**：进配置页。
- **转移**：换归属销售（有权限才有）。
- **报告**：生成企业诊断类报告（有权限才有）。
- **停止服务 / 恢复服务**：停了定时一般不跑。

### 3.3 进编辑后的页签

| 页签 | 干什么 |
|------|--------|
| 企业资料 | 名称、服务期、地区、官网 |
| 监测词配置 | 词组、检测问题、露出词、平台模式 |
| 监控计划 | 每天几点自动跑 |
| 竞品库 | 竞品名 |
| 知识库 | 看客户上传的文件 |

顺序建议：资料 → 监测词 → 计划 →（可选）竞品 / 知识库。

### 3.4 企业资料

填企业全称、服务期、官网、**服务地区**（影响按地区出结果）、品牌说明（内部看）。  
点 **保存企业资料**。

### 3.5 监测词配置

一个词组 = 一组监测关键词 + 一组露出词 + 勾选平台。

1. **新增词组**，状态选 **启用**（停用不参与定时）。
2. **监测关键词** = 直接扔给 AI 的**检测问题**（回车添加；可粘贴多行）。不要填公司全称凑数。
3. **露出词** = 在回答里认你们品牌的名字（短名、产品名）。× 删除。
4. **勾平台** → 弹 **选择监测模式** → 选一种 → **确认**（截图强制开）。
5. 勾上后右侧短标：
   - **快速**
   - **深度思考**
6. 改模式：再点整块平台卡片。
7. 取消勾选：点右侧 **×**。弹窗点「取消」不会乱勾。
8. 灰 /「无服务」/「已下架」：不能新勾。新平台不会自动勾，要人手点。
9. **保存监测词配置**。

深度思考相对更贵，心里有数。

### 3.6 监控计划

**新增时间** 配每天几点 → **保存监测计划**。  
时间对、服务中、词组启用、有平台有词，才会自动跑。仍不跑找技术。

### 3.7 竞品库 / 知识库

竞品：输入名 → **新增竞品** → 保存（按页上按钮）。  
知识库页签：运营端看客户上传文件，可预览 / 下载。

### 3.8 企业管理翻车点

- 保存后模式全变快速：每个平台重新选一次模式再保存。
- 详情里公司全称当监测词：刷新后再看；还不对再存一次监测词。
- 勾了平台却「没勾上」：硬刷新（Ctrl+F5）；取消用 ×。

---

## 4. 售前诊断

给**未签约 / 潜客**做诊断材料，不是企业管理里的日常监测。

1. **售前诊断** → **新建诊断**。
2. 第一步：品牌名称（必填）、竞品（逗号分隔）、监测地区、销售备注 → **下一步**。
3. 第二步：填检测问题（至少 1 个，最多约 5 个）；可用模板按钮。
4. 可选勾「创建后立即启动第 1 次抓取」。
5. **提交诊断任务**。

共九次抓取，按页面写的时段跑；全部完成后状态变 ready 才能导。

详情页常用按钮：

- **刷新**：看进度。
- **强制执行**（权限 + 未完成时）：催一把。
- **导出 HTML / 导出 PDF**（ready 后）。

页签：进度 / 报告 / 问题 / 信源 / 平台 / 配置。按需点。

---

## 5. 快照补录

抓取失败、或要覆盖已有答案时用。销售少碰，交付 / 运营常碰。

1. 筛：**企业**（建议先选具体企业）、检测日期、来源（GEO 监测 / 售前诊断）、平台、词组、监测词；可勾「仅待补录」。
2. **刷新**。
3. 点卡片进详情。
4. 按页面要求贴分享链接 / 回答正文 → 提交补录（保存后会重算排名等）。

状态大概两类：**待补录**、**可覆盖**。  
「全部企业」扫不全时按提示选具体企业再刷。

---

## 6. 报告中心（平台端）

1. 可按企业、关键词筛选。
2. 左侧点报告 → 右侧预览。
3. 导出 PDF / HTML / Word（有按钮且有权限才有）。

企业内部诊断也可从企业管理列表的 **报告** 生成。  
周期报告多由系统自动生成；客户端只看已发布的。

---

## 7. 用户管理

展开后一般有：

### 7.1 用户新增

1. 填账号、显示名、密码（至少 6 位）。
2. 选身份：平台运营端 / 客户企业端（可双身份）。
3. 客户身份：选已有企业，或填「新企业名称」让系统建公司。
4. 勾菜单权限 / 职位（按页上矩阵）。
5. **新增用户并保存权限**。

### 7.2 用户列表

筛：姓名账号、所属公司、身份、状态、已删除。

行上操作：

- **编辑/权限**
- **重置密码**
- **禁用 / 启用**
- **删除** / **恢复账号**

### 7.3 职位管理

建职位 → 勾这个职位默认菜单权限 → 保存。  
用户挂到职位后吃职位权限（再被个别身份权限覆盖的情况以实际页为准）。

---

## 8. 品牌洞察 / 信源分析（平台端）

都是看**已有监测结果**，先选企业（顶栏或页内企业筛选，以页面为准）。

**品牌洞察**：提及率、首位提及率、平均排名、情绪排行。筛时间、平台、问题后看图。  
**信源分析**：只重点展示标题/链接里带露出词的引用。可看类型分布、趋势、TOP 信源、明细。

没数据：检查企业有没有露出词、有没有跑出结果。

---

## 9. 模型平台

看平台目录：各平台是否上架、今天探活成败。

- **刷新**：拉最新目录 / 状态。
- 「无服务」「已下架」会出现在企业管理勾选里对应灰态；不要手工乱改库。

一般只看，不在这给企业勾监测平台（勾平台在企业管理 → 监测词配置）。

---

## 10. 预警阈值

两块：

1. **队列积压预警**：submit / sync 深度。点编辑 → 改预警值 / 严重值 → 保存。
2. **业务预警规则**：排名、失败率、余额等。同上。

上方有调度 / Celery 监控面板，异常找技术。  
改阈值影响告警，别乱拧。

---

## 11. 操作日志

按操作类型、关键词查 → **查询** → 可 **导出 CSV**。  
出事查「谁改过、什么时候」用这个。

---

## 12. 系统配置（偏技术）

常见子项：接口密钥、调度策略、缓存与队列、通知规则、菜单权限（改菜单显示名等）。

业务同学一般别动。动之前先问技术。页面上有：

- **刷新配置**
- 单行 **保存**
- **预览调度** / **立即执行到期调度**（会真跑任务，别随便点）
- **打开菜单配置管理**

# 乙、客户企业端

客户登录后看自家企业（不建别人企业）。

## 菜单一览

| 菜单 | 干什么 |
|------|--------|
| 运营工作台 | 健康分、趋势、平台表现 |
| 实时检测 | 查批次结果、排名矩阵、打开快照 |
| 品牌洞察 | 自家 vs 竞品 |
| 信源分析 | 带露出词的引用 |
| 报告中心 | 已发布周期报告 |
| 企业知识库 | 上传 / 预览资料 |
| 品牌诊断 / 推广链接检测 | 部分账号仍可见，以页面为准；核心日常看上面几项 |

---

## 1. 运营工作台

只读看板。首次空：等定时任务跑完。页上写了「无需手动提交」。  
可点入口跳到实时检测。

---

## 2. 实时检测

1. 筛：日期（近 7 / 30 / 自定义）、平台、词组、监控词、露出词、轮次。
2. 视图：**排名矩阵** 或 **逐条列表**。
3. **刷新**；矩阵可 **导出矩阵**。
4. 点词组 / 批次看本轮各平台结果。
5. **打开快照** 看当日回答截图；可看引用信源。

没有「手动提交检测」的主力入口；日常靠运营配的监控计划。结果不更新：联系运营查计划与权限。

---

## 3. 品牌洞察 / 信源分析

同平台端看图逻辑，只限于本企业。筛时间 / 平台 / 问题后看。

---

## 4. 报告中心（客户端）

一般只能看**已发布**周期报告。没有报告：联系运营。  
点列表 → 预览 → 有权限再导出。

---

## 5. 企业知识库

1. **上传资料**（PDF / Word / Markdown / TXT，单文件通常 ≤ 30MB）。
2. 列表搜索、点文件预览。
3. 无上传按钮 = 只读权限，找运营帮传。

运营也可在企业管理 → 知识库页签看你们传的文件。

---

# 丙、标准SOP（新建一家签约客户）

1. **用户管理**：建客户账号（绑企业）或先建企业再开账号。  
2. **企业管理**：新增企业 → 资料 → 监测词（词 + 露出词 + 平台模式）→ 监控计划 → 保存。  
3. 有审批：提醒有权限的人在 **操作审批** 通过。  
4. 等计划时间跑一轮 → 客户在 **实时检测 / 工作台** 验收。  
5. 交付报告：报告中心 / 企业管理「报告」。  
6. 潜客未签约：走 **售前诊断**，别跟日常企业配置搅在一起。

# 丁、谁找谁

| 现象 | 找谁 |
|------|------|
| 没有菜单 / 没有按钮 | 管理员开权限 / 职位 |
| 保存了不生效 | 操作审批是否待审；已通过还不行找技术 |
| 定时不跑 | 先自查服务状态、词组启用、平台、计划时间；再找技术 |
| 平台灰、无服务 | 模型平台目录状态；找技术 |
| 余额 / 队列报警 | 预警阈值 + 技术 |
| 抓取失败要补答案 | 快照补录 |

# 戊、名词对照

| 页面说法 | 意思 |
|----------|------|
| 监测关键词 | 问 AI 的问题 |
| 露出词 | 答案里认品牌用的短名 |
| 快速 / 深度思考 | 监测模式 |
| 平台运营端 / 客户企业端 | 两套登录身份 |
| 待审批 | 改动还没写生效 |
