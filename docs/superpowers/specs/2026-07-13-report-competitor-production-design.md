# 报告竞品模块正式生成链路改版设计

## 1. 目标

将桌面四份报告已经确认的竞品分析、企业高对比配色、排名风险表达、诊断实际执行时间展示和删除 AI 回答摘录等效果写入项目正式生成链路，同时同步周期报告样例生成器。

适用报告：

- 售前诊断报告
- 报告中心品牌诊断报告
- GEO 监测周报
- GEO 监测月报
- GEO 监测季报

## 2. 数据链路

诊断趋势的时间粒度为实际执行批次，而不是自然日。

时间取值优先级：

1. `LeadDiagnosisRun.schedule_label`
2. 调度上下文中的 `schedule_label`
3. `GeoMonitorSubtask.updated_at`
4. 无可用时间时显示“时间数据缺失”

同一天多次执行必须分别保留，按完整时间升序排列。不得在图表、排名矩阵或导出上下文中仅使用 `date()` 聚合。

周期报告继续按照自然周、自然月和自然季度聚合总体 KPI；只有诊断报告的批次趋势要求逐次展示。

## 3. 企业视觉映射

### 3.1 已确认配色

| 企业 | 颜色 | 线型 | 点形 |
|---|---|---|---|
| 本品牌 | `#0057D9` | 实线 | 圆点 |
| 分众传媒 | `#F28E2B` | 短虚线 | 方点 |
| 白马户外媒体 | `#009E73` | 点划线 | 三角 |
| 华铁传媒 | `#C43C92` | 长虚线 | 菱形 |
| 北京优视传媒 | `#7C3AED` | 短虚线 | 倒三角 |
| 德高中国 | `#008C95` | 点线 | 五边形 |

本品牌固定使用第一组视觉编码，线宽高于竞品。

### 3.2 未知竞品

新增竞品从高对比色板中稳定分配颜色、线型和点形。分配依据为规范化企业名称的稳定哈希，不使用 Python 进程随机化的内置 `hash()`，保证不同服务实例、不同报告类型和不同生成时间中同一企业映射一致。

视觉映射由一个共享模块提供，图表、HTML表格、图例、条形图和 Word/PDF导出共同调用，不允许各自维护颜色列表。

## 4. 排名风险规则

| 数值范围 | 状态 | 颜色 |
|---|---|---|
| `rank <= 3` | 优势 | 绿色 |
| `3 < rank <= 5` | 关注 | 黄色 |
| `5 < rank <= 7` | 预警 | 橙色 |
| `rank > 7` | 高风险 | 红色 |

无排名数据使用中性灰色和“—”，不得判定为高风险。

风险色用于排名徽标、表格底色或辅助标记；企业身份色用于折线、柱形、名称和图例。两类颜色含义不得混用。

## 5. 竞品内容结构

### 5.1 管理摘要

- 竞争格局：领先、追赶、预警梯队。
- 本品牌位置：当前排序、是否进入 Top3。
- 头部差距：提及率和平均排名差距。
- 最接近竞品：与本品牌综合差距最小的竞品。
- 一句话竞争态势结论。

### 5.2 运营明细

- 企业提及率、平均排名、Top3率和样本量。
- 分平台领先与落后情况。
- 分语义词竞品占位情况。
- 重点防守和优先追赶对象。
- 内容建设、权威信源、平台运营和口碑治理建议。
- 周报使用下周执行重点，月报使用下月运营重点，季报使用下季度策略重点。

结论首先由确定性规则生成。DeepSeek 启用时只能在已有数据范围内润色或补全文案，不能修改指标、虚构竞品或引入未配置市场份额。

数据不足时显示“当前样本暂不足”。

## 6. 模板变化

### 6.1 模力风格诊断模板

- 删除完整“AI 回答摘录”模块及空白占位。
- 竞品格局后增加管理摘要、风险图例和运营明细。
- 排名变化趋势使用实际执行时间。
- 平均排名趋势图使用共享企业视觉映射。
- 语义词竞品提及率条形图使用共享企业颜色。

### 6.2 Premium 与周期报告

- 在竞品相关模块加入管理摘要、运营明细和风险图例。
- 保留现有封面、KPI、趋势、信源、行动计划和免责声明结构。
- 周报、月报、季报的非竞品模块不得因本次改动改变。

### 6.3 Word/PDF

- HTML/PDF图表使用相同视觉映射。
- Word中的企业名称和图例使用相同颜色；无法表达复杂线型时必须保留点形或文字图例。
- 打印时不能只依赖颜色传递身份和风险含义。

## 8. 异常与降级

- 竞品为空：显示未配置竞品，不渲染空图表。
- 样本不足：显示明确提示，不填充演示数字。
- DeepSeek失败：回退规则文案，报告继续生成。
- Matplotlib或图表生成失败：保留表格和文字结论，不阻断整个报告导出。
- 实际时间缺失：显示时间缺失，不构造固定时段。

## 9. 测试与验收

自动化测试至少覆盖：

1. 同一天三个 `schedule_label` 输出三个趋势点。
2. `schedule_label` 缺失时回退 `updated_at`。
3. 同一企业在诊断、周报、月报、季报中的视觉映射一致。
4. 未知竞品跨进程映射稳定。
5. 排名风险阈值 `3/5/7` 的边界及小数值正确。
6. 无排名数据返回中性状态。
7. 模板不再输出“AI 回答摘录”。
8. 无竞品和样本不足场景正常降级。
9. 周/月/季非竞品章节保持原有顺序和内容。

视觉验收：

- 重新生成诊断、周报、月报、季报 HTML/PDF。
- 检查企业颜色、线型、点形、风险图例和中文标签。
- 检查分页、裁切、重叠和空白页。
- 运行完整后端测试和前端生产构建。
